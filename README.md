# 买吗 · BUY / NOT

一个帮助用户判断“此刻是否值得买”的十题互动网站。

## 使用方式

直接双击打开 `index.html` 即可，无需安装依赖或启动服务器。

## 判断方式

- 10 道题全部只需选择“是”或“否”。
- 6 个理性维度占综合分的 65%：真实需要、使用频率、预算边界、替代方案、长期价值、机会成本。
- 4 个感性维度占综合分的 35%：真实喜欢、为自己而买、冲动热度、后悔预警。
- 结果等级：

| 综合分 | 判断 |
| --- | --- |
| 90–100 | 可以放心买 |
| 66–89 | 可以买 |
| 44–65 | 再考虑考虑 |
| 0–43 | 暂时不需要买 |

除综合分以外，结果页还会分别展示理性与感性得分、支持与风险信号，以及针对最薄弱维度的具体行动建议。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式视觉与动效
- `app.js`：题目、计分、结果和交互

网站不调用外部服务，也不会保存作答记录。
